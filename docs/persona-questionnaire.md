# TwinSync — Ερωτηματολόγιο Twin → ZIP

**Πώς δουλεύει:** κάθε άτομο συμπληρώνει μόνο του το ερωτηματολόγιο (10–15′) και το στέλνει σε **νέο** chat στο ChatGPT, μαζί με την εντολή που υπάρχει ήδη στην αρχή του. Το ChatGPT δεν κάνει συνέντευξη: φτιάχνει κατευθείαν το `twinsync-<handle>.zip`. Στο TwinSync: **Νέο Twin → Εισαγωγή από ZIP**.

- Μόνο τα δικά σας δεδομένα, με τη συναίνεσή σας. Όχι μηνύματα ή στοιχεία τρίτων.
- Το repo είναι δημόσιο: **μην ανεβάσετε το ZIP στο GitHub**, μόνο στην εφαρμογή.
- Ό,τι στέλνετε στο ChatGPT φεύγει προς την OpenAI. Γράψτε μόνο ό,τι σας είναι άνετο.

## Αντιγράψτε από εδώ, συμπληρώστε μετά από κάθε «→» και στείλτε

```text
ΕΝΤΟΛΗ ΠΡΟΣ ΤΟ CHATGPT — διάβασε όλο το μήνυμα πριν απαντήσεις.

Είσαι μετατροπέας δεδομένων για την εφαρμογή TwinSync (ψηφιακά δίδυμα που αποφασίζουν και γράφουν όπως ο κάτοχός τους). Κάτω από την εντολή έχω συμπληρώσει ένα ερωτηματολόγιο για τον εαυτό μου. Μπορεί να έχω επισυνάψει και export συνομιλίας (.txt). ΔΕΝ θέλω συνέντευξη ούτε συμβουλές.

Κάνε ΜΟΝΟ αυτά, με τη σειρά:
1. Αν λείπει κάποιο πεδίο με *, ρώτα με ΜΟΝΟ γι' αυτά, σε ΕΝΑ μήνυμα με αριθμημένη λίστα, και περίμενε. Αν δεν λείπει τίποτα, προχώρα κατευθείαν.
2. Με Python (code interpreter) φτιάξε το αρχείο twinsync-<handle>.zip με την ΑΚΡΙΒΗ δομή παρακάτω και δώσε μου link λήψης.
3. Μετά το link γράψε σε έως 5 γραμμές τι θα μάθει το Twin για μένα και ποια προαιρετικά πεδία έμειναν κενά.

ΚΑΝΟΝΕΣ:
- Οι απαντήσεις μου μπαίνουν στα αρχεία ΑΥΤΟΥΣΙΕΣ: ίδιες λέξεις, ορθογραφία, τόνοι ή έλλειψή τους, greeklish, emoji. Μη διορθώνεις, μη συνοψίζεις, μη μεταφράζεις, μην προσθέτεις τίποτα. Η εφαρμογή ελέγχει ότι κάθε ανάμνηση είναι αυτούσιο απόσπασμα από τα αρχεία.
- Κενά πεδία απλώς παραλείπονται. Ποτέ μη γράψεις κάτι που δεν έγραψα.
- Αν επισύναψα export συνομιλίας: κράτα ΜΟΝΟ τις δικές μου γραμμές, αυτούσιες, χωρίς ημερομηνία, ώρα και όνομα αποστολέα. Διάλεξε έως 40, κατά προτίμηση για σχέδια, χρήματα, φαγητό, έξοδο, ταξίδια. Πέτα μηνύματα με τηλέφωνα, διευθύνσεις ή κωδικούς. Ονόματα τρίτων γίνονται αρχικά (π.χ. «Μ.»).
- Αρχεία UTF-8 χωρίς BOM, όλα στη ΡΙΖΑ του zip (όχι σε φάκελο).

ΔΟΜΗ ZIP:
persona.json → {"name": "<Α1>", "handle": "<Α2>", "emoji": "<Α3>", "bio": "<Α4>"}
01-profile.md      kind: document       → Α4, ΣΤ4, ΣΤ5
02-money-time.md   kind: note           → Β1–Β5, Γ1–Γ4
03-food.md         kind: note           → Δ1–Δ3
04-travel.md       kind: note           → Ε1–Ε5
05-going-out.md    kind: note           → ΣΤ1–ΣΤ3
06-decisions.md    kind: past_decision  → Ζ1–Ζ4
07-messages.md     kind: chat           → Η1–Η6
08-chat-export.md  kind: chat           → μόνο αν επισύναψα export
holdout.json                            → Θ1–Θ3 (ΔΕΝ είναι πηγή, είναι το τεστ)

Κάθε .md ξεκινά ΑΚΡΙΒΩΣ έτσι:
---
id: src-<handle>-<01..08>
kind: <όπως παραπάνω>
title: <ελληνικός τίτλος, π.χ. «Χρήματα και χρόνος»>
date: <σημερινή ημερομηνία YYYY-MM-DD>
synthetic: false
---

Σώμα των 01–06: για κάθε πεδίο που συμπλήρωσα, δύο γραμμές:
**Ε:** <το κείμενο της ερώτησης, όπως είναι στο ερωτηματολόγιο>
**Α:** <η απάντησή μου αυτούσια>
Στο 06 κάθε απόφαση ξεκινά με «## Απόφαση <αριθμός>» και ακολουθεί η απάντηση αυτούσια.
Σώμα των 07 και 08: ένα μήνυμα ανά γραμμή, αυτούσιο, χωρίς **Ε:**/**Α:**.

holdout.json:
{"personaHandle": "<Α2>", "cases": [{"question": "<σύντομη ερώτηση>", "category": "trip|food|entertainment|activity|gift|other", "options": [{"id": "a", "title": "<επιλογή>", "costPerPerson": <αριθμός ή null>, "features": ["<χαρακτηριστικά, όπως τα έγραψα>"], "endsAt": "<YYYY-MM-DDTHH:MM:00+02:00 ή null>"}, {"id": "b", "...": "..."}], "actualOptionId": "<a|b|c>", "note": "<το «γιατί» μου αυτούσιο>"}]}

========== ΕΡΩΤΗΜΑΤΟΛΟΓΙΟ ==========
(* = υποχρεωτικό. Γράψε όπως μιλάς, όχι «σωστά». Ποσά σε € ανά άτομο.)

Α. ΤΑΥΤΟΤΗΤΑ
Α1* Ονοματεπώνυμο →
Α2* Handle, μόνο λατινικά/τελείες (π.χ. panos.kouz) →
Α3 Ένα emoji που σε εκφράζει →
Α4* Bio σε μία γραμμή (σπουδές/δουλειά + 2–3 πράγματα που αγαπάς) →

Β. ΧΡΗΜΑΤΑ
Β1* Μέχρι πόσα δίνεις για φαγητό/ποτό έξω, και πάνω από πόσα λες όχι; →
Β2* Μέχρι πόσα για ένα διήμερο, όλα μαζί (μετακίνηση, ύπνος, φαγητό); →
Β3* Μέχρι πόσα για ένα τριήμερο; →
Β4 Για τι πληρώνεις ευχαρίστως παραπάνω; →
Β5 Σε τι δεν ξοδεύεις ποτέ; →

Γ. ΧΡΟΝΟΣ
Γ1* Σταθερές υποχρεώσεις με μέρα + ώρα (π.χ. «Δευτέρα 9:00 εργαστήριο», «Τετάρτη 19:00 προπόνηση») →
Γ2* Από ταξίδι πρέπει να έχεις γυρίσει το αργότερο: μέρα + ώρα + γιατί →
Γ3 Πιο νωρίς από τι ώρα ΔΕΝ ξεκινάς ταξίδι; →
Γ4 Μέρες του Δεκεμβρίου που δεν μπορείς →

Δ. ΦΑΓΗΤΟ
Δ1* Τι δεν τρως ή δεν μπορείς να φας (διατροφή, και αλλεργίες μόνο αν θες να το πεις) — ή «τρώω τα πάντα» →
Δ2 Αγαπημένο φαγητό/κουζίνα/μαγαζί και γιατί →
Δ3 Τι πίνεις (κρασί, μπύρα, κοκτέιλ, τίποτα) →

Ε. ΤΑΞΙΔΙ & ΔΙΑΜΟΝΗ
Ε1* Θάλασσα, βουνό ή πόλη, με σειρά προτίμησης, και γιατί →
Ε2 Πεζοπορία: πόσες ώρες το πολύ; →
Ε3* Διαμονή που ΔΕΝ δέχεσαι με τίποτα (σκηνή; κοινόχρηστο μπάνιο; κοιτώνας;) →
Ε4 Οδηγείς; Πόσες ώρες διαδρομής αντέχεις; →
Ε5 Το καλύτερο ταξίδι σου και γιατί, σε 1–2 γραμμές →

ΣΤ. ΕΞΟΔΟΣ & ΕΝΔΙΑΦΕΡΟΝΤΑ
ΣΤ1 Κλαμπ, μπαρ ή ήσυχο μαγαζί; Τι και γιατί →
ΣΤ2 Τι μουσική ακούς (2–3 καλλιτέχνες ή είδη) →
ΣΤ3 Θες να γνωρίζεις νέο κόσμο ή προτιμάς μόνο την παρέα; →
ΣΤ4 Χόμπι, αθλήματα, ό,τι σε ενθουσιάζει τώρα →
ΣΤ5* Τα 3 απόλυτα «όχι» σου σε οποιαδήποτε έξοδο ή ταξίδι →

Ζ. ΠΩΣ ΑΠΟΦΑΣΙΖΕΙΣ — 3 πραγματικές παλιές αποφάσεις
Γράψε: «Ανάμεσα σε … (κόστος) και … (κόστος) διάλεξα … γιατί …»
Ζ1* →
Ζ2* →
Ζ3 →
Ζ4 Σε τι υποχωρείς εύκολα για χάρη της παρέας, και σε τι ποτέ; →

Η. ΓΡΑΨΕ ΟΠΩΣ ΓΡΑΦΕΙΣ ΣΤΟ GROUP (μην το σκεφτείς, γράψε όπως θα το έστελνες)
Η1* Συμφωνείς με ένα σχέδιο →
Η2* Λες όχι σε ένα σχέδιο →
Η3* Γκρινιάζεις ότι κάτι είναι ακριβό →
Η4 Θα αργήσεις 20 λεπτά →
Η5 Προτείνεις κάτι για το Σάββατο →
Η6 (προαιρετικό) Επικόλλησε 10–30 δικά σου πραγματικά μηνύματα, ή επισύναψε WhatsApp export (συνομιλία → ⋮ → Περισσότερα → Εξαγωγή → Χωρίς πολυμέσα) →

Θ. ΤΕΣΤ «ΕΙΝΑΙ ΠΡΑΓΜΑΤΙΚΑ ΕΣΥ;» — ΔΕΝ μπαίνει στο Twin
2–3 ΑΛΛΕΣ πραγματικές αποφάσεις (όχι αυτές του Ζ). Γράψε:
«Ερώτηση | Επιλογή Α: κόστος, 2–3 χαρακτηριστικά, ώρα επιστροφής | Επιλογή Β: … | Διάλεξα: Α ή Β | Γιατί»
Θ1* →
Θ2* →
Θ3 →
```

## Μετά

1. Κατεβάστε το `twinsync-<handle>.zip` από το ChatGPT.
2. Στο TwinSync: **Αρχική → Νέο Twin (+) → Εισαγωγή από ZIP**. Η εφαρμογή:
   - δημιουργεί το Twin, ή ενημερώνει το υπάρχον με το ίδιο handle
   - αναλύει όλα τα αρχεία με AI
   - φτιάχνει την κάρτα ύφους
   - κρατά το `holdout.json` χωριστά, μόνο για την **Αξιολόγηση**
3. Στο προφίλ σας, καρτέλα **Προς έλεγχο**: επιβεβαιώστε ή διορθώστε όσα έμαθε το Twin. Αν όλα είναι σωστά, πατήστε «Επιβεβαίωση όλων».
4. Στη σελίδα **Αξιολόγηση**, πατήστε «Τρέξε live αξιολόγηση». Οι δικές σας αποφάσεις-τεστ εμφανίζονται με την ετικέτα «πραγματική απόφαση κατόχου».

Αν ξαναφτιάξετε το ZIP με περισσότερα στοιχεία, η νέα εισαγωγή αντικαθιστά τα αρχεία με το ίδιο όνομα. Δεν δημιουργεί διπλότυπα.
